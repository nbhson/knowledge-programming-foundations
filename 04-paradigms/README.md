# 🧠 Lớp 4: Paradigms (Học Thuyết Lập Trình)

> **Paradigms** là các **cách tư duy và tiếp cận vấn đề** khi viết code.
> Mỗi paradigm mang một triết lý riêng về cách tổ chức và thực thi chương trình.
>
> **Ví dụ:** Triết lý thiết kế — kiến trúc sư suy nghĩ theo cách nào.

---

## Danh Sách Các Paradigms

| # | Paradigm | Triết Lý | Đặc Điểm Chính |
|---|----------|---------|----------------|
| 4.1 | **Object-Oriented Programming (OOP)** | Tổ chức code theo đối tượng | 4 pillars: Encapsulation, Inheritance, Polymorphism, Abstraction |
| 4.2 | **Functional Programming (FP)** | Tổ chức theo hàm, tránh side effects | Pure Functions, Immutability, Higher-Order Functions, Function Composition |
| 4.3 | **Reactive Programming** | Tổ chức theo luồng dữ liệu và sự kiện | Observable streams, auto-propagate khi data thay đổi |
| 4.4 | **Procedural Programming** | Tổ chức theo quy trình (procedures) | Viết code tuần tự từ trên xuống |
| 4.5 | **Declarative vs Imperative** | Khai báo vs Thủ tục | Declarative: mô tả CÁI GÌ. Imperative: chỉ CÁCH làm |
| 4.6 | **Concurrent & Parallel Programming** | Song song và bất đồng bộ | Concurrent: nhiều task xen kẽ. Parallel: thực thi đồng thời trên nhiều cores |
