# 🚀 5.2.12 Rapid Application Development (RAD)

> Nhấn mạnh **tốc độ phát triển nhanh** thông qua việc xây dựng **prototype liên tục**, nhận phản hồi từ khách hàng và tái sử dụng linh kiện/code.

---

## 🎯 4 Pha chính trong RAD

1. **Requirements Planning:** Thảo luận và thống nhất mục tiêu tổng quan
2. **User Design (Prototyping):** Xây dựng prototype nhanh, user dùng thử và cho phản hồi ngay
3. **Rapid Construction:** Code chính thức dựa trên prototype đã duyệt
4. **Cutover:** Integration, testing, chuyển giao hệ thống
