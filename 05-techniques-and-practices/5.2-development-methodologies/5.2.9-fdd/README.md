# 🏗️ 5.2.9 Feature-Driven Development (FDD)

> Phương pháp Agile tập trung vào **xây dựng phần mềm theo từng tính năng cụ thể (feature)**, kết hợp thiết kế hướng đối tượng (OO Design) và quy trình ngắn hạn (2 tuần/feature).

---

## 🎯 5 Bước trong FDD

1. **Develop an Overall Model:** Dựng domain model tổng thể
2. **Build a Feature List:** Lập danh sách tính năng (nhỏ, có giá trị, dạng "<action> <result> <object>")
3. **Plan by Feature:** Phân công & lập lịch theo feature
4. **Design by Feature:** Thiết kế chi tiết cho nhóm feature nhỏ
5. **Build by Feature:** Code, review, test & tích hợp
